# KK短片诊断案例图谱

使用时先按用户作品选择一张或多张图谱，再读取列出的判断卡；最后按症状检索完整证据索引。案例图谱提供方法路径，不替代用户上传作品的真实时间点和截图证据。

## 生活 Vlog 图谱（vlog）

适用症状：日常记录像流水账；开头平；小事件讲不清

必须优先读取的判断卡：JC-01、JC-02、JC-04、JC-12、JC-14、JC-15、JC-19、JC-36、JC-41、JC-46、JC-57、JC-58

## 旅拍图谱（travel）

适用症状：景点多却没有故事；旅拍开场无进入感；只有风景没有在地感

必须优先读取的判断卡：JC-07、JC-11、JC-16、JC-17、JC-18、JC-29、JC-37、JC-41、JC-45、JC-52、JC-58、JC-63

## 情绪片图谱（emotional）

适用症状：画面好看却感受不到情绪；人物没有变化；音乐盖住人物状态

必须优先读取的判断卡：JC-03、JC-19、JC-30、JC-33、JC-35、JC-39

## 产品片图谱（product）

适用症状：产品只是在转圈展示；卖点看不懂；产品音效廉价

必须优先读取的判断卡：JC-01、JC-09、JC-21、JC-22、JC-28、JC-31、JC-43、JC-44、JC-47、JC-48、JC-58、JC-59

## 民宿与空间图谱（space）

适用症状：空间漂亮但没感觉；民宿像设施清单；房间没有纵深

必须优先读取的判断卡：JC-05、JC-12、JC-23、JC-24、JC-25、JC-29、JC-47、JC-48

## 人物片图谱（character）

适用症状：人物像工具人；事件发生后没有感受；表情没被看见

必须优先读取的判断卡：JC-03、JC-13、JC-19、JC-20、JC-39

## 剧情与叙事图谱（narrative）

适用症状：片子没有推进；没有目标或转折；结尾不成立

必须优先读取的判断卡：JC-06、JC-10、JC-13、JC-18、JC-33、JC-36

必须优先读取的判断卡：JC-26、JC-27、JC-28、JC-29、JC-30、JC-31、JC-32、JC-33、JC-34、JC-41、JC-59、JC-61、JC-62

## 教程与口播图谱（tutorial）

适用症状：观众学不会；讲解拖沓；口播一直一个画面

必须优先读取的判断卡：JC-02、JC-08、JC-09、JC-34、JC-40、JC-43
