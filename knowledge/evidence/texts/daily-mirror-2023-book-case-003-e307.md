# 快慢结合和声音匹配：有节奏变化的旅拍开场剪辑技巧

【每日一镜第307期】来自《Zedd x Beautiful Destinations - Epos I》

这个短片是作者在香港的一个旅拍作品。利用快慢结合和声音匹配在开场片段中的运用吸引观众。

开场的第一个镜头组，以慢速仰拍的方式呈现了一座夹缝中的楼宇。（图3-1）这个镜头以缓慢的节奏开始，让观众有时间去吸收画面的内容。然后，节奏突然加快，伴随着三声敲鼓的声音，连接了三个截然不同的镜头：敲鼓、（图3-2）剁鱼、（图3-3）钉鞋（图3-4）。通过声音匹配的方式将三个无关的镜头连接在一起。

在快速推镜之后，画面给到了补鞋师傅的近景，（图3-5）随后慢慢淡黑。这个镜头的结束，（图3-6）也标志着第一个快慢结合的镜头组的完结。

接下来的镜头转到了人物的背影，（图3-7）与之前的仰拍楼宇镜头有着异曲同工之妙。同样是以慢速开始，然后手快速收回，紧接着是一系列素材的变速或者叠化。（图3-8）这些快速的变化再配上加速、风声、whoosh、上升等多种音效的混合，使得整个片段更加富有层次感和动感。

在音效的设计上，每一个音效的出现都与画面的节奏紧密相连。比如，在片段停顿的地方，压塑料的音效突然出现，为接下来的章节标题的展示做好了铺垫。

技巧提示：

快慢结合，重要的一个效果标准是，快素材之间的连接质量怎么样，而快素材的连接，往往听觉比视觉效果重要，也就是音效的设计，上面案例中，快素材之间用了声音相似匹配，由于鼓、剁鱼还有钉鞋都是敲击声，这让这三个不相干的素材得以连接。因此，我们在平时剪辑的时候，寻找这种相同元素去连接也是我们需要去不断观察和练习的技能。
