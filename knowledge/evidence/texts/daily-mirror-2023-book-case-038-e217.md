# 木工工作如何拍摄：掌控节奏与变速

【每日一镜第217期】来自 《industrial TVC- drills RONIX Tools commercial》

如果你是一位短视频摄影师，面对木工和他们的工具，想要创作出令人眼前一亮的短片，却苦于没有灵感，来看看这个短片

在短片创作中，节奏是至关重要的元素。差不多每个重音的地方，都是几个比较有力量感的镜头。想象一下，木工抬起盒盖展示logo，（图2-1）安好电池，（图2-2）冲击木板，（图2-3）这些动作的瞬间都与背景音乐的重音相吻合。

然后，我们要聊聊曲线变速。以钻螺丝的镜头为例，并不是全程升格，而是在最前面很短的时间是常速，然后突然变慢。这种突然的变速，可以给观众带来一种冲击感，使得电钻的力量得以更充分地展现。

除了节奏和变速，光影的运用也是拍摄短片中不可或缺的一环。手拿手电钻的镜头从屏幕左侧到右侧的过程也是先常速最后那一下慢动作。（图2-4）在这一过程中我们采用了硬光直接和摄影机正对向然后平移的方式来营造出一种强烈的逆光效果。

这个短片里的变速和卡点是值得我们反复学习的。通过短片我们可以感受到，当运镜速度的改变和背景音乐的重音相结合，传递出的节奏和力量感就会增加。因此，我们在前期拍摄构思的时候，就应当想好你想向观众传递的情绪，然后反推出需要拍摄的镜头和剪辑的方式。

这里有几个关键点：

强调关键动作：通过慢动作展示关键细节，如木工工具与木材接触的瞬间，强化观众对这一动作的印象。

变速剪辑营造紧张与释放：快速剪辑与慢动作交替，可以营造紧张感，随后通过慢动作提供视觉上的释放和焦点。

节奏匹配：选择具有明显节奏感的音乐，确保木工的动作或镜头的切换与音乐的节拍或重音相匹配。
