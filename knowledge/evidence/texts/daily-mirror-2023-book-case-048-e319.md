# 如何拍出焦虑感：寻找充电器

【每日一镜第319期】来自《THE NEED ; one minute short movie》

想象一下，如果一个人急于找到他的充电器，却四处寻找无果，那种焦虑感是如何通过镜头来传达的呢？

首先，我们可以运用近景或特写镜头，捕捉人物面部的微妙变化以及身体的动作。此外，双手捂脸、咬牙切齿，以及翻箱倒柜等动作，都是表现人物内心急切和无奈的好方法。

其次，通过快速的剪辑手法，我们可以在短时间内切换不同的场景，展示人物在不同地点寻找充电器的过程。这种快速的节奏可以增加紧张感。此外，运用一些特殊的拍摄角度，如低角度或倾斜角度，可以为我们营造一种更加紧迫和不安的氛围。拍摄人物周围的物品，如杂乱的电线、空无一物的插座，或是散落的电池等，都能够有效地增强这种焦虑感。

最后，千万不要忘记音效和音乐的重要性。钟表的滴答声、手机低电量的提示音、加速的心跳声、急促的呼吸声以及紧张的背景音乐等，都能够让观众更加深入地感受到人物内心的焦虑。

在观看这个短片时，大家可以发现其中已经运用了一些表达焦虑感的手法，如翻箱倒柜、（图2-1）双手捂脸（图2-2）以及钟表的声音和画面（图2-3）等。然而，节奏感并没有通过剪辑得到充分地体现。为了营造出更加紧张的寻找过程，我们可以尝试将人物到处搜寻、钟表走动的画面、埋头苦找的镜头以及流汗的细节等进行交叉快速剪辑。这样一来，整个寻找过程将会呈现出一种更加紧迫和焦虑的节奏感。

通过近景或特写镜头捕捉人物面部的微妙变化，如皱眉、咬牙等，以及身体的动作，如翻箱倒柜、双手捂脸等，都是有效传达人物内心焦虑状态的手法。这些镜头能够让观众直观地感受到人物的急切和无奈。

运用低角度、倾斜角度等特殊拍摄角度，以及紧凑的构图方式，可以营造出更加紧迫和不安的氛围。这些技巧能够增强画面的表现力，使观众更加深入地感受到人物的焦虑。
