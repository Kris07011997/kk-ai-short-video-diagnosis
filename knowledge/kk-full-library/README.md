# 全量教学补充证据层｜v1

本层将可读取的《每日一镜》、长拉片、书稿、教学课件、案例表格和教学视频，转为可按需检索的便携证据。它服务于“为什么这样诊断、可以怎么改”，不能替代用户作品的实际看片。

## 内容与用途

| 内容 | 可用于 | 不能用于 |
| --- | --- | --- |
| `kk-method-library.md` | 阅读KK方法卡的适用条件、低成本替代与真实出处 | 把方法编号当作用户作品的证据 |
| `kk-case-evidence-deduped.jsonl` | 精确检索案例表中的镜头、构图、剪辑、声音与备注 | 复制完整镜头顺序或原文案 |
| `kk-all-teaching-evidence.jsonl` | 检索书稿、课件、字幕、思维图与教学文本中的判断过程 | 编造未明确出现的原片时间码或音效 |
| `case-atlas/` | 先读当前题材的案例总览；产品/广告/空间必读第 11 图谱 | 把图谱标题视为诊断结论 |
| `video-visual-evidence/` | 核对重点产品、空间、品牌案例的视觉状态 | 把关键帧当作原片逐镜时间码 |
| `video-teaching-evidence/` | 补足无配套文字教学视频中的讲解线索与关键帧 | 未交叉核对就升级成KK判断卡 |

## 证据等级

1. **用户作品真实证据**：诊断结论的唯一直接依据，必须有用户视频时间点、截图及可听见的声音事实。
2. **已验证KK方法证据**：判断卡、完整案例表、书稿/课件明确文本，可标注为“KK方法级参考”。
3. **教学视频补充证据**：机器转写与稀疏关键帧，标为“待交叉核对”。其时间点用于定位KK讲解，绝不等于所分析原案例的时间码。

## 诊断检索顺序

1. 先看片，写清用户作品的片型、症状和真实时间点；
2. 读取原有题材图谱与判断卡；
3. 用“片型 + 症状 + 镜头/声音方法”检索完整案例表和教学文字；
4. 产品、广告、企业、民宿、酒店、餐厅、空间作品必读 `case-atlas/11_产品广告与商业空间_完整版.md`；
5. 需要验证教学视频画面时才读取关键帧，转写与关键帧必须交叉核对；
6. 最终结论回到用户自己的画面与声音，给出可执行的重剪或补拍动作。

本层不含任何KK原始视频，也没有开发者电脑路径。使用者无需配置《每日一镜》或长教程目录。
