# 短视频声音诊断框架

只有完整听过用户视频后才使用本框架。声音诊断的目标不是让每个镜头都有音效，而是让声音帮助观众理解动作、空间、节奏和情绪。

## 1. 先建立声音清单

按时间点记录实际听到的五类声音：

1. 对白或旁白：承担信息和人物表达。
2. 环境与氛围底音：交代空间、真实感和持续情绪。
3. 拟声与动作音：让动作、材质和距离可感知。
4. 设计音效：Whoosh、上升、下降、重击、Stutter等，用于连接、强调和风格化。
5. 音乐与短配乐：建立段落、速度和总体情绪。

先判断每一层的功能，再判断是否需要添加、删除或调整。不能因为2025案例大量使用音效，就默认用户作品也要堆满音效。

## 2. 六个诊断维度

### A. 声音动机与同步

- 画面中是否出现值得被听见的动作、材质、开关、碰撞或视线变化？
- 拟声是否落在动作顶点，提前或滞后会不会削弱动作？
- 没有可见或可推断的声音来源时，设计音效是否仍服务情绪或转场？

常用动作：移动、裁短、替换、删除、在动作顶点对齐。参考2025-479、490、495、511、512。

### B. 空间与真实感

- 音乐回落或对白停顿后，场景是否变成不自然的“真空”？
- 室内、街道、咖啡馆、自然环境是否具有轻微但持续的空间底音？
- 景别由远到近时，环境声和拟声的距离、响度与细节是否发生变化？

常用动作：补环境底音、做淡入淡出、按景别改变强弱、保留必要现场声。参考2025-473、479、527、529。

### C. 层次与声音分工

- 单一拟声是否显得薄？是否需要上升音、氛围层或重击层补充方向、空间或重量？
- 叠加的每一层是否各自承担功能，还是多个相似声音互相遮盖？
- 旁白出现时，音乐和效果是否主动让位？

常用动作：分层、删去重复层、降低陪衬层、保留主体层。参考2025-446、453、454、492、517、527。

### D. 音乐切断与段落衔接

- 音乐被剪短时是否突然断掉？
- 音乐高潮、回落和重新起势是否与画面段落一致？
- Whoosh、Impact、空镜、拟声或环境声能否成为自然的声音断点？

常用动作：在音乐回落点切断、用短Whoosh或Impact收口、用环境声承接安静段、再用上升音进入下一段。参考2025-470、478、497、502、503、532、535。

### E. 转场、方向与速度匹配

- 镜头向上、向下、推近、拉远、甩动或快速切换时，声音方向和速度是否匹配？
- 每次转场都用同一种Whoosh，是否造成重复和疲劳？
- 快切是否只有逐镜拟声，缺少覆盖整组镜头的起势或收尾？

常用动作：调整音效速度、区分上升与下降、给镜头组设计首尾、改变连续转场的音色。参考2025-454、463、474、484、488、489、493、496、509、539。

### F. 密度、对比与留白

- 声音是否从头到尾一样满、一样响、一样快？
- 重击和卡点是否过多，导致每个镜头都像重点？
- 静音、骤停、环境声独奏或强弱反差能否让下一次声音更有效？

常用动作：静音、降低密度、删去部分卡点、建立快慢段、保留一段自然声。参考2025-459、482、525、529、531、535。

## 3. 判断优先级

按以下顺序处理：

1. 对白、旁白听不清或关键声音信息缺失；
2. 声画明显错位、音乐切断突兀；
3. 场景缺少空间底音，或声音关系不真实；
4. 层次、重量、速度和转场衔接；
5. 风格化音效与装饰。

声音问题可以成为三个核心问题之一。只有当“信息可听性”和“声音叙事”是两个独立原因时，才拆成两个问题，避免把缺音效、音乐太满、节奏单一重复成三个相似结论。

## 4. 报告证据格式

每个声音问题必须写清：

- 时间点：问题从哪里开始、在哪里发生变化；
- 实际听到：旁白、音乐、环境声、拟声和设计音效分别是什么；
- 功能判断：缺少、重复、错位、突兀、遮盖或密度不变；
- 修改动作：删、移、裁、淡入淡出、降低、提高、叠加、替换、留白；
- 参考案例：案例编号、标题和证据等级；
- 预期变化：只描述理解、真实感、空间、节奏或情绪，不承诺流量。

若没有响度测量、分轨或可视波形，不写具体分贝数，不断言频率冲突。无法听取完整声音时，明确退回画面诊断，不凭标题或字幕推测声音结构。
